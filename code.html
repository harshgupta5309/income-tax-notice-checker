How Does It Work?

To check litigation notices, click the Sync Notices button. The automation engine runs the following steps:

  • 1. Launches a secure backend browser session to access the Income Tax E-Portal.
  • 2. Logs in using client credentials from the Excel Registry Sheet.
  • 3. Navigates to the official e-Proceedings panel.
  • 4. Automatically downloads notices in CSV format (AX, BX, AY, and BY files) to the Destination folder.
  • 5. Highlights new notices and lists all downloads for tracking and reconciliation.

Server Delays & Timeout Options

If the portal takes longer than 20 seconds to respond, the system displays a choice box inside the progress window. You can choose to Retry the current client taxpayer from the beginning of login, or Abort the Scraping run entirely.
